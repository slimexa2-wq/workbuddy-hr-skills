# 祥能人力固定周期报表（周一 3 项 + 月初 4 项）自动化套件

## 一、全局交付红线（`deliverable_zero_fill_and_no_annotation_rule`）

1. **产物即最终产物，零批注（`Comment = 0`）**
   - 交付的所有 Excel 文件必须直接达到可发领导群、可归档的定稿状态。
   - **严禁添加任何单元格批注（`Comment`）**，严禁在主表底部追加“核验说明/待确认”等废话文字，严禁使用临时标黄底色；所有公式异常、台账外推荐人或追问事项一律单独输出到控制台或 Markdown 汇报简报的内部复核章节。
2. **无数据一律填 `0`，绝不留空**
   - 数值列凡无数据或未发生变动时**必须填入数字 `0`**，文本/说明列无数据时填入 `"/"` 或 `"0"`，严禁留空（`None` 或 `""`）。
3. **WPS 占用预检与原子备份护栏（`check_wps_lock`）**
   - 修改任何已有 Excel 前，脚本自动执行 `lsof` 检查 `wpsoffice` / `Microsoft Excel` 进程占用及同目录 `~$` 临时锁文件。
   - 若文件正被 WPS/Excel 打开，**立即阻断退出（Exit Code `2`）并提示用户先保存关闭**，彻底杜绝后台写入后被 WPS 内存旧画面在关闭时覆盖回磁盘。
   - 写入前自动在 `/tmp/{文件名}_backup_{YYYYMMDD_HHMMSS}.xlsx` 生成原子备份。

## 三、四大核心模块口径铁律

### 模块 1：WPS 占用预检与原子备份（`check-lock`）
```bash
$PYTHON $SUITE check-lock "/Users/wangmini/Downloads/资源目标达成推进表-10月.xlsx"
```
- 写入任何已有文件前自动调用 `check_wps_lock()`，发现 `wpsoffice` / `Excel` 打开句柄或 `~$` 锁文件立即抛错阻断。

### 模块 2：祥能自招月度达成核算 5 条铁律（`self-recruit`）
1. **数据源与月份过滤**：读取《所有企业名单汇总》（自动兼容 BIFF8 `.xls`、`.xlsx` 与 HTML 表格），筛选 `供应商 == "祥能自招"` 且 `入职日期` 以目标月份 `YYYY-MM` 开头；若离职年份存在明显笔误（如入职 `2026-10-xx`、离职误填 `2020-10-xx`），自动修复为同年 `2026`。
2. **在职满 7 天条件**：`离职日期为空（仍在职）` 或 `(离职日期 - 入职日期).days >= 7` 计入；`< 7` 天或日期倒挂（`< 0`）一律剔除。
3. **面试结果过滤**：仅计入 `已入职`、`已离职`、`已签约` 三种状态；填了入职日期但状态为 `中途放弃`、`未入职` 的一律剔除。
4. **特殊映射与部门归口**：
   - 推荐人手机号 `135 5134 4625`（或 `13551344625`）固定归入 **杨水容**（宜宾分公司）；
   - **李一航** 所属部门固定归入 **郫都分公司**。
5. **台账更新与透视表同步**：
   - 台账内无达成人员在当月列**一律填数字 `0`**（严禁留空、严禁加批注）；
   - 同步更新个人累计达成 `G` 列（`=SUM(I{r}:T{r})`）、达成率 `H` 列（`=G{r}/F{r}`）、底部 `合计` 行及右侧 `W3:AJ12` 部门透视汇总表；
   - 台账外推荐人（如空推荐人、外人手机号）不计入主表，单独输出核对清单。
   - **2026-10 基准回测金标准**：台账 62 人 10 月合计 **`254` 人**（郫都分公司 `59` 人、人力资源部 `7` 人、宜宾分公司 `90` 人、双流分公司 `50` 人、龙泉分公司 `23` 人、保安公司 `21` 人、绵阳分公司 `4` 人、公共事务部 `0` 人、重庆分公司 `0` 人），全年累计达成 **`2721` 人**。

### 模块 3：项目需求周报清洗与勾稽核验（`project-demand`）
- 自动扫描《分公司企业需求动态表.xlsx》各分公司明细行与小计/总计公式：
  1. **纵向小计公式漏行修复**：如 11 月双流分公司 `M102` 原公式 `=SUM(M71:M100)` 漏算第 101 行 `大茂丰安保`（2人），自动修正为真实合计 `11` 人；
  2. **总计行跨列引用错位修复**：如 11 月及 10 月总计行 `M173:P173` 原公式误写为 `+V29 / +W29 / +Y29 / +Z29`（未引用宜宾小计 `M29:P29`），自动修正补齐宜宾分公司需求（11月第一周全集团真实总需求为 **`363` 人** 而非原表错误的 `346` 人）；
  3. **脏字符清洗**：自动剥离单元格内换行符（如 `'5\n'`）与纯空格（`'  '`），防止 Excel `SUM` 忽略文本型数字。

### 模块 4：学生工需求与校招资源周报生成（`student-worker`）
- 自动解析《学生工进度》上、下半表与《校招-项目》：
  1. **表头错别字自动修正**：`样能人力学生工需求记录表(11月)` $\rightarrow$ `祥能人力学生工需求记录表(11月)`；
  2. **Excel 日期序列号还原**：将 `46256`（`2026-08-22`）、`46259`（`2026-08-25`）、`46274`（`2026-09-09`）、`46285`（`2026-09-20`）、`46304`（`2026-10-09`）、`46310`（`2026-10-15`）、`46322`（`2026-10-27`）、`46361`（`2026-12-05`）等序列号全部还原为 `YYYY-MM-DD`；
  3. **多维状态归类与存量预警**：自动汇总各分公司需求缺口（如 11月绵阳京东方 300人 + 华丰 200人 + 郫都索尔思 100人 = 600人）、16 所合作院校已到岗在职人数（154人）、校方卡点/确认不来明细，以及《校招-项目》存量批次到期离场与新批次待补录预警。

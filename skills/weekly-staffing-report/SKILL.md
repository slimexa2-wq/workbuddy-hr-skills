# 祥能人力周度在离职数据统计（在离职周报）

## 一、核心交付铁律（知其然知其所以然）

1. **产物即最终产物，格式严格一致、严禁随意修改**
   - 交付的 Excel 文件（`祥能人力周报_YYYYMMDD-YYYYMMDD.xlsx`）必须直接达到可发领导、可归档的定稿状态。
   - **严禁添加任何单元格批注（`Comment`）**，严禁在表格底部追加“统计口径/核验说明/待确认”等文字行，严禁使用临时标黄底色（如 `#FFF2CC`），严禁擅自更改表头、列宽、行高、配色或公式结构。
2. **无数据一律填 `0`，绝不留空**
   - 所有数值列（`C~I` 列：上期在职合计、本期自招、本期供应商、本期在职合计、本期入职、本期离职、环比变化）凡无数据或未发生变动时，**必须填入数字 `0`**，严禁留空（`None` 或空字符串），避免出现“左右有数字、中间突然空一格”的视觉断裂。
3. **四大视觉与筛选设计规范**
   - **有数据区域全部加清晰黑色细实线边框（`#000000 thin`）**：增强行列边界辨识度，便于人眼看数不串行。
   - **全列统一居中对齐（`A~I` 列水平居中 + 垂直居中）**：包含 `B` 列“项目名称”在内全部居中，保持版面规整美观。
   - **各分公司小计行整行浅蓝底色（`#D9E1F2`）+ 全行加粗（`bold=True`）**：不仅包含第 4 行总部“小计”，还包含各分公司汇总行（`B` 列标注 `XX个项目（含X个外送）` 的行），使分公司汇总数据一目了然，且支持在 Excel 中**按单元格颜色快速筛选**各分公司小计。
   - **环比变化列（`I` 列）严格执行“正红、负绿、无变化黑”**：
     - `> 0`（人数增加）：**红色字体（`#C00000`）**（小计行/总计行加粗）
     - `< 0`（人数减少）：**绿色字体（`#375623`）**（小计行/总计行加粗）
     - `= 0`（无变化）：**纯黑字体（`#000000`）**（小计行/总计行加粗）
     - 作用：符合国内报表直觉，一眼看出各项目人数增减，且支持在 Excel 中**按字体颜色快速筛选**人数增加或减少的项目。

## 二、工作簿结构与精确样式参数

工作簿固定包含 3 张工作表：`周度数据表`、`人数减少明细`、`人数增加明细`，每张表均为 `9` 列（`A~I` 列）：

### 1. 列宽与行高标准
- **列宽**：`A=15.0`，`B=28.0`，`C=12.0`，`D=13.0`，`E=13.0`，`F=13.0`，`G=13.0`，`H=13.0`，`I=13.0`
- **行高**：
  - 第 1 行（大标题行）：`33.75pt`（`A1:I1` 合并居中）
  - 第 2 行（表头行）：`48.0pt`
  - 第 3 行及以下（所有数据行、小计行、总计行）：统一 `21.75pt`

### 2. 表头与字体配色标准
- **字体族**：全表统一 `Noto Sans CJK SC`
- **第 1 行（大标题）**：
  - `周度数据表`：`祥能人力周度在离职数据统计表（M月D日—M月D日）`
  - `人数减少明细`：`人数减少明细（M月D日—M月D日）`
  - `人数增加明细`：`人数增加明细（M月D日—M月D日）`
  - 样式：`13pt`、加粗、白色字体（`#FFFFFF`）、深蓝底色（`#1F4E78`）
- **第 2 行（列标题，必须写具体日期，严禁用“本期自招”等泛化词）**：
  - 依次为：`['区域', '项目名称', '{上期结束M月D日}在职合计', '{本期结束M月D日}自招', '{本期结束M月D日}供应商', '{本期结束M月D日}在职合计', '本期入职', '本期离职', '环比变化']`
  - 样式：`11pt`、加粗、白色字体（`#FFFFFF`）、中蓝底色（`#2F5597`）
- **数据行**：`11pt`、常规（`bold=False`）、无底色填充，`A~H` 列纯黑（`#000000`），`I` 列按正红（`#C00000`）/负绿（`#375623`）/零黑（`#000000`）着色。
- **分公司小计行**：
  - `A` 列为区域名（如 `总部`、`宜宾分公司`、`绵阳分公司`、`重庆分公司`、`双流分公司`、`龙泉分公司`、`郫都分公司`、`保安子公司`）。
  - `B` 列：总部写 `小计`；各分公司写 `{N}个项目` 或 `{N}个项目（含{M}个外送）`。
  - 样式：整行 `A~I` 列浅蓝底色（`#D9E1F2`）、`11pt` 加粗（`bold=True`），`C~H` 列用 `=SUM(C{起}:C{止})` 纵向求和，`I` 列用 `=F{r}-C{r}` 且按正红/负绿/零黑加粗着色。
- **总计行（`周度数据表` 最后一行）**：
  - `A` 列：`总计`；`B` 列：`{总项目数}个项目（含{总外送数}个外送）`。
  - `C~H` 列：`=SUM(各小计行单元格)`；`I` 列：`=F{r}-C{r}`。
  - 样式：整行 `A~I` 列绿底（`#70AD47`）、`11pt` 加粗（`bold=True`），`I` 列按正红/负绿/零黑加粗着色。
- **《人数减少明细》与《人数增加明细》子表**：
  - 直接从 `周度数据表` 筛选 `环比变化 < 0`（进人数减少明细）与 `环比变化 > 0`（进人数增加明细）的项目行，按分公司顺序排列。
  - **子表不设小计行和合计行**，`C~H` 列填直接数值（无数据填 `0`），`I` 列公式为 `=F{r}-C{r}`，严禁使用 `=IF(ISBLANK(...))` 等冗余跨表公式。

### 1. 各分子公司原表解析要点
以集团上周定稿表为基线（上周 `F` 列自动转为本周 `C` 列），按分公司规则抽取 `D（自招）、E（供应商）、G（入职）、H（离职）` 及备注栏的变动原因：
- **宜宾/绵阳/双流**：原表常在同一工作表内按周纵向追加数据块，须定位最底部最新日期块读取。
- **保安子公司**：原表拆分为“本公司自招、甲方自招、供应商”，须按集团口径归并：`自招 = 本公司自招`，`供应商 = 甲方自招 + 供应商`。
- **固定项目别名映射**：注意分公司简称与集团总表标准名的对应（如双流 `中电熊猫` $\rightarrow$ `熊猫电子派遣`）。

### 2. 五道自动硬核验关卡（问题单独列清单追问分公司，绝不写进 Excel 主表）
1. **横向勾稽**：`原表在职合计 == 自招 + 供应商`。
2. **纵向求和**：`原表小计行 == SUM(原表各项目明细)`（防止原表 `SUM` 公式漏选新增行，如龙泉漏算棒棒娃入职）。
3. **存量与流量闭环**：`本期在职合计(F) - 上期在职合计(C) == 本期入职(G) - 本期离职(H)`（抓出漏记入离职或偷改基数的项目）。
4. **跨周基数一致性**：`分公司本周原表填的“上期在职” == 集团上周定稿表的“期末在职”`。
5. **≥10 人变动原因必填检查**：所有 `|环比变化| ≥ 10` 的项目，检查原表备注栏是否已写明具体变动原因；未写明的一并列入《分公司追问清单》。

## 四、向领导汇报的固定文案格式（严禁随意改动）

每次交付定稿 Excel 时，同步按以下**一字不差的固定格式**生成领导汇报文案（筛选阈值：**单项目 `|环比变化| ≥ 10 人` 必须汇报并注明原因**；同一分公司有多个项目达标时合并在同一条内，用分号 `；` 分隔）：

```text
@龙章其 @徐万霞 @肖小松 各位领导：

截至{YYYY}年{M}月{D}日，按已收到的项目明细统计，本期在职人数合计{本期总人数}人，较{上期M}月{上期D}日{上期总人数}人{增加/减少}{净变化绝对值}人。已报在职项目{已报项目数}个（含{外送数}个外送）；本统计窗口为{开始M}月{开始D}日至{结束M}月{结束D}日。现将本周人员变动情况汇报如下：

✨相对增长项目：
1、{分公司名称}：{项目名称}增加{N}人，为{变动原因}；
2、...

‼主要减少项目：
1、{分公司名称}：{项目名称}减少{N}人，为{变动原因}；
2、...

下附在职明细、人数减少、人数增加明细，请大家查收。
```
